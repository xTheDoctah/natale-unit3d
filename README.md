# natale-unit3d

Tema natalizio per UNIT3D: un foglio di stile esterno che si applica sopra il tema esistente.

- palette rosso / verde / oro
- neve che cade (non blocca i click)
- lucine lampeggianti sul bordo alto
- niente animazioni se il sistema chiede `prefers-reduced-motion`

## Uso

Aggiungi l'URL del CSS come stylesheet esterno in UNIT3D:

```
https://cdn.jsdelivr.net/gh/xTheDoctah/natale-unit3d@main/natale-unit3d.css
```

Tutti i colori e la velocità della neve si cambiano dalle variabili in `:root`.
